# Umowy — wzory

To wzory robocze do uzupełnienia, nie porada prawna. Przy większych kwotach, licencjach
i umowach z dużymi markami niech zerknie prawnik.

Potrzebne typy (Claude przygotuje konkretną wersję na podstawie briefu):
- umowa o dzieło z przeniesieniem praw autorskich (reżyser, operator, montażysta)
- umowa z klientem na produkcję teledysku / reklamy
- zgoda na wykorzystanie wizerunku (aktorzy, statyści)
- umowa najmu lokacji
- NDA

Przy każdej umowie ustalamy: strony, przedmiot, termin, wynagrodzenie i płatności,
pola eksploatacji (prawa autorskie), poprawki, odpowiedzialność, odstąpienie.
